<h2 style={heading}>What this is</h2>

PocketUI is a library of reusable, responsive React Native components. One typed codebase renders on iOS, Android and the web through `react-native-web`, and this Storybook redeploys automatically on every merge to `main`.

Every component ships with:

- **Typed props** with JSDoc, shown in the Docs tab
- **A story for every variant and state**
- **Unit tests** with React Native Testing Library
- **Accessibility checks** in the a11y panel
- **Light and dark mode**, driven entirely by theme tokens
